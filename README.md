# Campus Library Management System

## Overview
Campus Library Management System is a Python-based project designed to manage basic library operations in a simple and organized way.

## Features
- Add and manage books
- Issue books
- Return books
- View book status
- Display library information
- Simple menu-driven interface

## Technologies Used
- Python
- Python Lists and Dictionaries
- Functions
- Modular Python files

## Project Structure
- `main.py` – Main program and menu
- `data.py` – Library data
- `library.py` – Library operations
- `reports.py` – Reports and book status
- `validators.py` – Input validation
- `test_library.py` – Basic testing

## How to Run
1. Open the project folder in VS Code.
2. Run `main.py`.
3. Select an option from the menu.
4. Follow the instructions displayed on the screen.

## Workflow
Start → Menu → Select Operation → Process Data → Display Result → Exit

## Purpose
The project demonstrates the use of basic Python programming concepts to solve a practical campus library management problem.
