# Project Statement

## Problem Statement
Managing books manually in a campus library can make it difficult to track available and issued books. A simple digital system can make these basic operations easier and more organized.

## Scope
The Campus Library Management System focuses on basic book management using a Python-based application. It handles book records, issuing, returning, book status, and basic library information.

## Target Users
- Students
- Library staff
- Small campus libraries

## High-Level Features
- Add books
- Issue books
- Return books
- View book availability and status
- Display library information
- Menu-driven interaction

## Expected Outcome
The system provides a simple and organized way to perform common library book-management operations using Python.
